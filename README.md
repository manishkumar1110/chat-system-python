# Chat System

A beginner-friendly Python OOP mini project that simulates a basic chatroom system.

## Features

* Create users
* Send messages
* Store messages in a chatroom
* Assign a unique ID to each message
* Display messages with the sender's username

## Concepts Used

* Classes and Objects
* Constructors
* Instance Attributes
* Class Attributes
* Methods
* Object Relationships
* `__str__()` Method

## Technologies

* Python
* Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python file:

```bash
python chat_system.py
```

## Project Purpose

This project was created to practice Python OOP concepts by building a simple chatroom system.
